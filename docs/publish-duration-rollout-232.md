# 发布视频时长门禁变更（Issue #232）

## 验证

发布队列现在统一使用 `backend/publish_policy.py` 的 15–300 秒策略。回归测试覆盖 150 秒以上、162.8 秒、300 秒边界及超过 300 秒的拒绝路径；部署后应使用发布页创建一个 162.8 秒视频任务，确认队列接受且既有分辨率、可播放性和 GPU-only 质量检查仍执行。

本次代码变更不写入数据库，也不重跑已成功任务。162.8 秒源视频应在部署环境中通过现有 GPU 重剪入口重新生成；生成后用远端 GPU 质量检查确认 `duration <= 300`、文件可解码、质量分数和硬门禁均通过，再仅更新该目标任务/分组的待发布产物。

## 备份与回滚

部署前备份 `backend/publish_scheduler.py`、`backend/publish_policy.py`、前端构建产物和目标分组的媒体/数据库快照，并记录备份时间与校验和。回滚时恢复这些文件和前端产物，重启服务；不要回滚或批量改写无关发布任务。代码回滚会将门禁恢复到变更前的 150 秒策略，已生成的新媒体保留为源文件之外的独立产物，便于再次验证。
