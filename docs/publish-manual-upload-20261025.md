# 发布窗口手动上传成片

在“创建发布任务”的视频选择区域增加手动上传入口。支持一次选择多个MP4/MOV成片、逐个上传进度、取消后续上传、逐文件失败提示；成功项立即加入“自定义上传”分组并选中，可与既有视频一起发布，沿用本批描述、标签、账号及挂车商品。每个视频仍创建独立发布任务。自定义上传允许选择任意直播间的有效商品链接。

新接口POST /api/publish-videos/upload，只保存并校验用户成片，不创建recordings行、不转写、不剪辑、不提交GPU任务、不自动发布。遵循既有发布时长15–300秒，单文件≤1000MB；检查真实容器、视频流、尺寸和时长，保留原始字节。按SHA256内容寻址，数据库事务串行化重复上传，重试同一内容不会重复建分组。失败临时文件清理；显式关闭SQLite连接。新分组editing_mode=manual_upload、enabled=0，避免进入自动加工队列，但已完成classic版本可从发布窗口选择。

生产存储默认\\10.190.0.222\disk2\douyin-203-f-media\publish_uploads，可通过PUBLISH_UPLOAD_DIR覆盖，不继续占用C/F盘成果空间。已用susun交互会话验证创建/读写/删除专用测试文件，disk2剩余约3.6TB。请求体由现有Web框架接收，上传期间仍可能使用系统临时目录缓存；最终成片存放disk2。

验证：本地单元测试通过2项；本地缺少FastAPI因此HTTP测试跳过，未安装新依赖。203已有FastAPI/httpx，独立临时数据库真实16秒720×1280 H.264/AAC视频HTTP上传通过、字节SHA一致；重复上传复用同一分组；坏文件/空文件/错误扩展名/超限拒绝；临时文件清理；recordings及publish_tasks均0。前端测试多文件、部分失败继续、去重选择、保留共享文案/标签/商品、取消以及自定义分组跨直播间选品通过；Vue脚本/模板与生产bundle语法检查通过。测试视频没有写入生产商品/分组/发布任务库。

版本控制包含后端模块、前端共享上传组件、漂移保护补丁、部署器、针对性测试及本文档。生产部署备份main.py和入口HTML，保留原静态资产、哈希保护rollback.py及桌面启动任务恢复脚本。回退只恢复路由/前端入口；上传后产生的用户成片和分组保留，不恢复整库、不删除视频。生产挂车及最终发布仍走现有流程，由用户创建/确认发布任务。
