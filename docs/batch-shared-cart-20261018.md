# Shared cart for batch publishing

User requested one common product selection for every video in a single create operation. The selection controller now retains cart choices while switching the active video and freezes one common product-id list/no-cart setting before submission. Every request receives its own array copy of that same selection. Titles, descriptions, tags, export version and staggered scheduling remain per-video. Explicit no-cart applies to the entire batch. Empty-cart and over-five selections stop before any request; successful tasks are still removed before a partial retry so they are not submitted twice.

Only frontend code changed. Existing tasks were not modified or retried, no work was posted and no backend/GPU service was restarted. The production bundle patch replaces only the shared selection helper and its instruction text, retaining group search/multi-select and Oxygen matching.
