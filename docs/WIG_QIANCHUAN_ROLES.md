# 假发品类投流角色与硬规则（项目级）

## 角色分工

- **产品经理：小贾**：三步内容模型——前 3 秒真实痛点；中间 10–15 秒展示发网/发际线/梳理或佩戴前后反差；结尾约 5 秒真实效果、退换货/运费险等信任证明。通用必须有“摇头晃脑”或“风吹”慢动作，禁止空洞“赶紧下单”。
- **千川投流专家：小川**：必须填写主攻人群、排除人群、出价系数；素材生命周期 10–12 天，第 7 天按 CTR/CVR 决策。
- **短视频剪辑专家：小映**：模板为头皮/发际线微距 15–20 秒、佩戴全流程 30 秒内、佩戴前后反差 15–25 秒、真实用户开箱实测 30–40 秒；保留纹理/原声；每条新素材至少 3 项去重。
- **广告视觉专家：Leo**：禁止过度磨皮、美白、柔光；展示发丝、网底透肉、发际线衔接；圆润无衬线、白字黑描边、暖棕关键词位于下方 1/3；刚需用对比拼图/头皮特写，时尚用高颅顶侧颜/甩发抓拍。
- **AI 专家：小智**：每条 A 痛点、B 解决方案、C 信任背书三套文案；冷启动等额测试，优胜按 CTR>8% 或目标 ROI 追加到 70%，其余 30%继续测试；禁止 AI 生成人物佩戴假发画面。
- **系统运维专家：小维**：监控 API、队列、延迟、缓存、日志；Windows GPU 温度/显存/驱动/CUDA/FFmpeg；macOS 仅控制面和网络资源。每日检查磁盘 <20%、GPU 僵尸进程、延迟 >100ms、丢包 >1%；故障 3 分钟内报告，每周健康周报。

## 硬门禁

`backend/qianchuan_policy.py` 是唯一可审计规则实现。千川生成请求必须提供目标人群、排除人群、出价系数、模板、三版本文案、信任证明、动态稳定证据、至少三项去重动作、真实感检查，并声明 `remote-gpu` 执行节点。任一缺失则状态为质量失败，不得标记可投放；AI 生成人物佩戴假发画面直接拒绝。导演版不受此门禁影响。

## 人群与模板映射

| 模板 | 推荐人群 |
|---|---|
| 头皮/发际线微距 15–20 秒 | 中老年刚需群、产后妈妈群 |
| 佩戴全流程 30 秒内 | 产后妈妈群、中老年刚需群 |
| 佩戴前后反差 15–25 秒 | 职场白领群、时尚变美群 |
| 真实用户开箱实测 30–40 秒 | 四类人群均可，必须指定主攻人群 |

## 运维运行说明

- 每日运行 `scripts/daily_wig_ops.sh`，输出 API/队列/延迟/缓存/日志、远端 GPU 进程与资源、磁盘和网络巡检；本机仅检查控制面，不执行媒体作业。
- 每周运行同脚本的 `weekly` 参数生成周报，保留输出作为审计记录。
- GPU 故障时任务只等待远端节点恢复，禁止本机 fallback。
