## Approved cleanup procedure (later, after explicit operator confirmation)

Re-run the inventory and review every `recording_id` and path. Deletion is not part of the inventory command. For an individually confirmed recording, use the existing authenticated API endpoint:

```text
DELETE /api/recordings/{recording_id}/local-file
```

The endpoint marks the recording as locally deleted and removes the local artifact; it must not be called for an inventory row until the operator explicitly confirms that row. Re-run the dry-run inventory afterwards to verify the result.

Remote backend/database verification remains an operational deployment step: run the same read-only command against the active backend's mounted database and media directory before any cleanup approval. Missing or invalid duration is reported as `duration_unavailable`, never as a deletion candidate.
