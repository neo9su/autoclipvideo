# Issue 234：GPU-only 导演成片验收与回滚

## 验收样本（只读记录）

执行验收时选择 `director_status != 2`、存在可读 MP4 且存在非空 SRT 的最小
`group_id/recording_id`。在此文件或工单评论中记录：样本 ID、UTC 时间戳、部署
版本/提交号、远端 GPU job ID，以及远端探测结果；不得记录凭据、环境变量值或主机
敏感路径。不得通过修改生产状态制造成功结果。

必须由 GPU 节点完成以下只读证据：

1. SRT 非空并包含至少一个有效 timed cue，转录状态为完成。
2. 最终 MP4 的 ffprobe 含一个视频流和一个音频流，时长在发布门禁内。
3. GPU 节点抽取至少一个字幕时间点的视频帧，人工或视觉检查能看到字幕文字。
4. 配音 WAV 可解码，最终音频流时长与配音/视频同步且非静音。
5. 记录 `execution_node=remote-gpu`、job ID、部署版本和上述检查时间。

## 部署

1. 发布控制面与 GPU 服务同一提交号，先部署 GPU 服务并确认 `/director-jobs` 可用。
2. 仅选未成功的最小样本运行导演流程；不要重跑已成功视频。
3. 使用 GPU 服务的 `/director-jobs/{job_id}/quality` 取得 ffprobe/decode 证据，
   再保存脱敏后的报告到工单。
4. 验收通过后观察一个未成功样本的状态流转，确认字幕或配音缺失会保持失败，
   不会写入最终完成状态。

## 回滚

停止派发新的导演任务，恢复上一个已验证的控制面和 GPU 服务版本；不要删除已产出
的文件或篡改生产状态。对进行中的 job 等待失败/超时回收后，再恢复派发。回滚后
重新执行远端健康检查和一个非生产验收样本，并在工单记录版本与时间戳。
